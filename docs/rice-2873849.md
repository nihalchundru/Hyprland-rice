## 4. Shells and bars

### 4a. Shell switcher

There are two switchers. They do different things.

**`rofi-shell-switch.sh`, bound to `SUPER+D`.** This is the full layout switcher. It shows a rofi menu titled "Select Desktop Layout" with 5 options:

| Option | What it does |
|---|---|
| Default Shell (Waybar) | Kills quickshell and ChillPill, copies `keybindings.lua` to `current_profile_binds.lua`, reloads Hyprland, starts `qs -p pill`, `qs -p widgets`, `qs -p cava-visualizer`, and waybar if it isn't running |
| NothingShell (Quickshell) | Copies `quickshell/nothingshell/hypr/nothingshell.lua` to `current_profile_binds.lua`, runs matugen theme, reloads Hyprland, starts `quickshell --path ~/.config/quickshell/nothingshell`. **The source file is missing; see section 8.** |
| ChillPill-Shell (Dynamic Layout) | Copies `~/.config/hypr/chill.conf` to `current_profile_binds.lua` and runs `chillpill-shell`. **The repo has `chill.lua`, not `chill.conf`; see section 8.** |
| Serpantinum shell | Copies `~/serpantinum/compositors/hyprland/config/keybinds.lua` and starts `~/.local/bin/serpantinumd`. The path is `~/serpantinum/...`, but the repo keeps it at top-level `serpantinum/`, so this only works if the repo is cloned to `~`. |
| Material 3 Shell | Copies `~/.config/hypr/m3.lua` to `current_profile_binds.lua`, reloads Hyprland, starts `quickshell --path ~/.config/quickshell/m3` |

Every option except the default one replaces the loaded bind file. Switching to m3 therefore swaps the whole active keybind set for `m3.lua`.

It also starts 4 background Quickshell instances on every run: `applets`, `theme-switcher`, `wallpaper-picker`, and `osd`.

**`shell-switch.sh`, bound to `ALT+CTRL+S`.** This is a smaller switcher with 2 options: `hyde` and `ambxst`.
- It saves the choice to `~/.config/hypr/active-shell` (default `hyde`).
- Switching to `ambxst` kills waybar, hyprpanel, `qs -c`, and swaync, starts `ambxst`, and unbinds the HyDE keys with `hyprctl keyword unbind`.
- Switching back to `hyde` kills ambxst and restores the binds with `hyprctl reload`.
- It writes debug output to `/tmp/hyprtest.log`.

The README says `ALT+CTRL+S` launches NothingShell. The bind actually calls `shell-switch.sh`, which only offers `hyde` and `ambxst`.
